## Tallying points

[[page]]

### Trees

*A Tree is formed by 1 green token, placed on top of 0, 1, or 2 brown tokens to create Trees of size 1, 2, or 3.*

The height of each Tree determines the number of points you score:

- **Brown tokens with no green on top:** 0 points.
- **Size 1:** 1 point.
- **Size 2:** 3 points.
- **Size 3:** 7 points.

### Mountains

*A Mountain is a stack made of 1, 2, or 3 gray tokens.*

The height of each Mountain determines the number of points you score. However, a Mountain is worth 0 points if it is not adjacent to another Mountain.

- **Height 1:** 1 point.
- **Height 2:** 3 points.
- **Height 3:** 7 points.

### Fields

*A Field is formed by at least 2 yellow tokens in a contiguous group.*

You score 5 points for each Field formed by 2 or more contiguous yellow tokens. A lone yellow token scores 0.

To maximize your scoring, you should create small groups separated from each other. For example, if your Field is formed by 4 or more contiguous tokens, it only counts as a single Field and is only worth 5 points.

### Water, side A: the River

*A River is a string of consecutive blue tokens.*

The length of the River determines the number of points you earn. Count the number of tokens from one end of the river to the other by the shortest path (ends included).

You only score your best river. If the river's path contains more than 6 consecutive tokens, score 4 points for each token beyond the 6th.

- **1 token:** 0 points.
- **2 tokens:** 2 points.
- **3 tokens:** 5 points.
- **4 tokens:** 8 points.
- **5 tokens:** 11 points.
- **6 tokens:** 15 points.
- **Each token beyond 6:** +4 points.

*Example: one blue token sits off the shortest path, so it doesn't count. The river is 6 tokens long and scores 15.*

### Water, side B: the Islands

*If using Side B of the Personal board, the blue tokens are scored differently. Each space or group of spaces separated from each other by blue tokens forms an Island.*

You score 5 points for each island.

> NOTE: You always have at least 1 island, even if you don't create any separation using blue tokens.

*Example: Johan has created 4 islands. Therefore, he scores 20 points.*
